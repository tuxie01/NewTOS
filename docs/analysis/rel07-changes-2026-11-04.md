# NewTOS 0.7 – fact list for the release notes (REL07 step 3 input)

Date 2026-11-04. Range `v0.6.1..HEAD` = 411 commits (254 docs, 51 test, 48 fix,
48 feat, 7 chore, 2 build, 1 refactor). Sources: git subjects/bodies,
docs/STATUS.md (Recent Decisions 2026-11-04, queue), TASK files named below.
Dated snapshot: historical, not authoritative. Issue numbers only where a task
or commit names them.

## 1. Visible to testers

Fixed crashes / hangs
1. zView no longer crashes after returning from a started program (`Pexec(4)`); child page tables were freed while still in use. User run: 60 zView starts without crash. Ticket stays "to be tested". PROC08, `01eb7709` (earlier recurrence 2026-11-04 on the Pi, `6b80f14d`).
2. Programs that read/write/execute address 0 now end like an Atari bus error instead of silently working; the kernel survives. MEM12, `34530791`; TeraDesk reads of `_sysbase`/system vectors fixed for it, `0edf53d0`, `b03aadab`; Super/Supexec are kernel traps again, `60d3c4fd`.
3. USB command ring closed properly: a device tree needing more than 15 xHCI commands (hub plus several HIDs) no longer loses the later devices. USB01 F1, `7e7fbafa`.

Desktop and dialogs
4. Several AES fixes to match EmuTOS: window lock handling (A118 `ded51d9e`), menu message goes to the menu-bar owner (A117 `eaf32b04`), appl_write blocks on a full queue (A116 `b7be9bb1`), scheduler order (A115 `e7754b16`), text caret in edit fields (A111 `033da16f`), key-state bits (A126 `6ea5f883`).
5. Text programs that use VT52 escape sequences (cursor, clear, inverse) now show correct output instead of garbage. CON04, `9409f35a`.

File selector
6. Slider is operable (click in the track pages 9 lines, drag works like EmuTOS), plus mouse-wheel scrolling in the file selector. A128, GitHub #9 and #16, `df2c7501`; independent tester PASS, real Pi only in the tester scenario.

USB input
7. Wireless receivers (Logitech Unifying, Rii X8, Cherry DW 9000) now give a working mouse: the mouse sits on a second interface behind a keyboard interface. USB01 F3, GitHub #3, `be506300`; confirmed on real hardware by Ragnar (STATUS 2026-11-04 USB01 row); wheel of the DW 9000 works.
8. Only real HID boot keyboards/mice are taken as input devices (no more mis-taken interfaces); held keys are kept on an ErrorRollOver report; a Configure-Endpoint timeout no longer causes a wrong fallback. USB01, `190281c6`, `795066d9`, `8c112965`.
9. New diagnostic tool USBSNAP.NCP records what a USB device reports (testers can send it). USB01 K1-K10, `cf396382`, `46d37272`.

Files / drives
10. Closing a file sets the archive bit (as EmuTOS). FS21, `43b5789a`.
11. Setting a path after a drive re-login, and drive re-login after a media change, behave like EmuTOS. FS28 `5b7c1d2e`, FS20 `d6ff251b`, FS22 `b2eb3e0e`.
12. Without a battery clock the date starts at the kernel build date (00:00) instead of 1980-01-01 or a file date. XBIOS12, `6796787c`.

Apps
13. TeraDesk: overscan switched off (no Atari hardware), cookie jar read correctly. SDK07 `58e35ac8`, SDK04 C6 `8da6370e`. HypView: .REF files, zView colours fixed. SDK04, `1ca7d09a`.

Diagnostics
14. When a program crashes, the crash screen can show a diagnosis block (page-table walk and "ladder"). Build with feature `crash-walk`; the 0.7 card kernel is meant to include it. Testers: photograph the screen. PROC08, `371c50fd`, `5abcc20c`, `1452cc15`.
15. The product version now comes from one place; boot screen, `ver` and desktop About show "NewTOS 0.7". REL07, `797e0078`.

## 2. Under the hood (counts from `git log v0.6.1..HEAD`)

- BIOS/XBIOS audit fixes against EmuTOS (Setexc, Getmpb, Kbshift, Bconmap, Iorec, Bioskeys, MIDI/IKBD, AUX, vectors; BIOS01-17, XBIOS01-05/12/18, ~25 fix/feat commits).
- GEMDOS fixes (Fclose, Dsetpath, media change, d_fname, Fgetdta; FS20-23, FS28, MEM11).
- AES fixes (A111, A115-A118, A126, A128: 8 commits).
- Memory protection MEM12 (page 0 read-only, super state), `_MCH`/`_IDT` cookies (ARCH06, COOK02), SDK parity/struct fixes (SDK01-08).
- Verification tooling: pinned EmuTOS oracle, tosdump/tosdiff cases, dependency graph, doc-check pre-commit hook, image manifests, tester run sheets (about 60 test and tool commits; TOOL02-30).

## 3. Still known limitations (re-checked against STATUS/TASK 2026-11-04)

- No 68000 programs; one program at a time plus accessories; no sound; no network; FAT16 only; Pi 4 only; no printing/serial port (all unchanged from 0.6.1; no ticket opened in range that changes them; sound/network/FAT32 are roadmap, not re-verified in code here).
- Battery clock: still none (RTC01 not done); clock now starts at the build date (XBIOS12), the 0.6.1 sentence "from the kernel file" is outdated.
- Wheel of wired mice that send the wheel only in report protocol (Logitech B100, RPi mouse): open. USB03, GitHub #8; middle button (button 3) also pending there.
- Menu entries needing several clicks / menu highlight stays black (Ragnar, #3): open, not reproduced here, cause research only. A127.
- PROC08: fix is on the card, "to be tested"; may still recur, report with photo.
- DOOM freeze in menu on the Pi: deferred, only with accessory X-Shot and without `serial=on`. DOOM01.
- Dark edge strips in the file selector pattern: open. A129.
- Hot-plug, absolute pointers, port reset, mouse buttons 4/5: open (P3). USB04.
- Not re-verified by me: Shutdown halts on purpose; endless loop cannot be ended with Ctrl+Alt+Del (both from 0.6.1 README; no commit changing them seen).

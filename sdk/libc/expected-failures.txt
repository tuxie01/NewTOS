# expected-failures.txt -- the mintlib files that are KNOWN not to compile for
# NewTOS/AArch64, with the reason. One "<path>  <reason>" per line, paths
# relative to the extracted mintlib tree, "#" starts a comment.
#
# build-libc.sh compares the actual failure set against this list on every run
# (sdk/lib-stale.sh, lib_check_failures). A file that fails and is NOT listed
# here stops the build; a listed file that starts to compile is announced so
# this list can be shortened. Before TASK/T02 neither happened -- the failure
# list went to build/failed.txt and nowhere else, and the callers ran
# build-libc.sh with >/dev/null 2>&1 on top of that. That is how setsysvar.c
# and unix/sysinfo.c stayed broken for months (both compile since e503efd).
#
# This list is a RECORD, not an approval. The judgement column below is from
# TASK/T02; each entry that is not "hardware absent" is a real gap with a
# ticket of its own. Do not repair these files as a side effect of a
# toolchain change.
#
# Diagnostics below verified against sdk/libc/build/obj/*.err, 2026-09-16.

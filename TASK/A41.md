## The core

`tools/mkrsc.py` aborts on a CICON resource ("new-format (CICONBLK)
.rsc not supported"), although `CONF_WITH_COLOUR_ICONS` is **on** in the
target profile Falcon030/TOS4 (`make 512`).

This directly affects TeraDesk's `cicons.rsc` (classic 63 788 B), which is
therefore deliberately not installed.

## Context

Related to [A38](A38.md): the native form would be larger than
`RSC_CAP`. Both points together decide whether colour icons can be
loaded at all.

## Working rule

[Common rules and measurement limits](README.md) apply. The project principle
for a proven deviation from EmuTOS is **align**, not justify.
Test before fix; a green host test does not replace an open hardware acceptance.
Line numbers in older tickets have shifted since the repairs of 2026-09-12 —
rely on symbol names, not on foreign line numbers.

# V27 — `rect_from_ptsin`: `x2 - x1 + 1` laeuft auf `i16` ueber

Status: **OFFEN** (2026-11-05) · Prioritaet: **P4** · Typ: Robustheit, gelesen — Nebenbefund aus [V19](V19.md)

Developer V19: bei extremen `PTSIN`-Werten laeuft `x2 - x1 + 1` in `rect_from_ptsin`
(`tos-api/src/vdi/raster.rs`) auf `i16` ueber; im Dev-Profil eine Panik, im Release-Profil
(Karte) Umlauf. Soll aus EmuTOS (`vdi/vdi_raster.c`, WORD-Arithmetik) festhalten, dann
gleichziehen; Hosttest.

Nachtrag (V29-Developer, 2026-11-06): `gdp_justified` rechnet `(max_x - width)` ohne WORD-Umlauf;
ein extremes `max_x` (z. B. -32768) bringt den Dev-Build zum Panic, EmuTOS laeuft als WORD ueber.

[Gemeinsame Regeln](README.md) gelten.

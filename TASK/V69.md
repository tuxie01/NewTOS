Type: developer, then tester. Owner decision 2026-11-18 (TASK/V61.md): both VDI depths, selectable at boot, 16
planes the default; ADR-038 is the contract for the 32-plane setting. Slice of the series V62-V69 cut from the

## Scope

ADR-038 point 13 (iii) and (iv): the tosdump caps at 16 planes lifted, 32-plane expected values from ADR-038 labelled
"NewTOS contract", never "oracle"; program acceptance at 32 planes (zView, HighWire, DOOM); the patches the owner
decides for programs that break at 32 (TeraDesk's 17-entry table indexed by the plane count, `present`'s hardwired 16,
HighWire's 8-byte `ULONG`), each as a patch file in `sdk/overlays/`, upstream unchanged.

Sources: ADR-038 in `docs/MEMORY.md` (the contract; where it generalises an EmuTOS rule it cites the rule),
`docs/analysis/vdi-32bit-scope-2026-11-18.md` §1.2 (the change sites by file and function), TASK/V61.md step 2.
Before code: the spec files under `docs/api/vdi/` that this slice changes are extended for the 32-plane
setting (spec gate, researcher), since no EmuTOS path exists above 16 planes.

Depends on: V62-V68.

## Spec gate (researcher, 2026-11-18): two parts

Landed: `docs/TOS-REFERENCE-DUMPER.md`, section "The 32-plane setting: tosdump at vdiplanes=32" (part A: change set,
table classification, expected values, wide record, wide icprobe), and
`docs/analysis/v69-programs-at-32-planes-2026-11-18.md` (part B: the programs, read and measured, options).

Part A, tosdump at 32 planes, starts now (lead's reading of the tool design; the acceptance criteria above are
unchanged):

- The 16-plane tables, their record and their frozen references are not touched; the 32-plane tables are new files
  and their dumps go into a new dump area with the wide record. Enlarging the existing record would invalidate every
  frozen raster reference.
- Where the "NewTOS contract" label lives (table header, dumper log line, baseline name, area name) is fixed by the
  developer as the spec section proposes and stated in the receipt.
- The developer's first step is a run of the existing VDI tables at `vdiplanes=32` and a per-case list of what
  differs; the gate recorded counts only.
- Tests never assert the unused byte of a screen pixel ("paint before you copy").

Part B, the programs, waits for the owner: the Video options dialog of TeraDesk, PRESENT's 16-plane forms, HighWire
(no build recipe exists), zView (measure only). The developer's commit for part A sets line 3 to IMPLEMENTED with

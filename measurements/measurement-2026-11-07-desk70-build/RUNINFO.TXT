WHAT CHANGED (product)
  portable_fini() in sdk/overlays/coremark/newtos/core_portme.c: after the existing fflush(stdout), it calls
  Dgetpath(buf, 0). If the current directory is NOT the root ("" -- docs/api/gemdos/directory/47-dgetpath.md), it prints
  "Press any key to exit." and waits in Crawcin. This is after stop_time() and after the last result line, so it is
  outside the timed region. Only core_portme.c changed (CoreMark run rules); build-coremark.sh's MD5 check of the six
  frozen files passed (build/build-coremark.log).
  Why the root means "started from \AUTO\": an \AUTO\ program starts in the root of the boot drive (EmuTOS
  bios/bios.c:685-695 sets no directory; the child inherits initial_basepage's directories, bdos/proc.c:396-410;
  spec docs/api/gemdos/process/_run-ownership-curdir.md sections 4.2 and 6.5). The desktop sets the current directory
  to the application's (or the top window's) directory before the launch (desk/desksupp.c:880-915), inherited through
  shel_write's sh_apdir (aes/gemshlib.c:109-125,174-175; spec section 4.4).

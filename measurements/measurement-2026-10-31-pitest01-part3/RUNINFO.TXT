                     the boot partition, as a plan entry like every listed file (dry run new/changed/same,
                     copy via temporary name, read back after remount, `file` line). Needs --allow-boot-config

                     first file is written. Part 2 saved only replaced *.img files, during the copy loop. --write
                     into a run dir that already has card-before/ is refused (an earlier backup is never
                     overwritten).
  Manifest keys:     new `cmdline <card-name> <file> <sha256>`, `cmdline_active <card-name> -> cmdline.txt`,

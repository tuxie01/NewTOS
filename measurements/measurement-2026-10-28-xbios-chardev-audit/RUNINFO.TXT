THE PROBES (method/xcprobe.c, method/xkprobe.c; method/build-xcprobe.sh <repo> <scratch>)
  Same C source, m68k-atari-mint-gcc 7.5.0 + mintlib / clang aarch64 + SDK mintlib + sdk/newtos.ld;
  calls through mintlib's osbind.h macros / trap_14_*; structures are mintlib's (_IOREC, _KEYTAB,
  _KBDVECS, _BCONMAP, _MAPTAB). m68k PRGs are not bit-reproducible between builds (symbol table); the
  binaries in probe/ are the ones every final run used. NAPs reproduce.
  xcprobe: R Kbrate set/query/mask/restore; S Rsconf set/query (baud, ucr, rsr) and restore; B Bconmap
  (-1, -2 + the BCONMAP it points at, invalid devices, remap 7/6/8/9 and restore); I Iorec 0..2 + the
  IOREC it points at, invalid devices; K Keytbl query + tables (CRC32 of norm/shft/caps, alt pair
  lists), set arms, Bioskeys, restore; V Kbdvbase slots; W Ikbdws 0x1C/0x88/0x16 with counting
  clockvec/statvec/joyvec hooks (100 ticks each); M Midiws (1 and 256 bytes) and Bcostat(3).
  XCIOFL (-DVARIANT=1): io = Iorec(1); io->ibufhd = io->ibuftl; in user mode, "before" flushed first.
  XCKTNL (-DVARIANT=2): Keytbl(NULL,-1,-1), Bioskeys(), Keytbl(-1,-1,-1)->unshift.
  xkprobe: mousevec counting hook + Keytbl(my_n) (my_n[i] = i^0x55), "KEYREADY", then input: right
  button down/up (one IKBD mouse packet each), 'a', Bioskeys, 'a'.
  EmuTOS input: method/run-emutos-xkeys.sh, Hatari --cmd-fifo "hatari-event rightdown/rightup/
  keydown 30/keyup 30" (method/xkeys-hatari.txt) after KEYREADY, --fast-forward off.
  NewTOS input: injector kernel, method/xkeys-ikbd.txt (0xF9 0 0, 0xF8 0 0, 0x1E/0x9E twice).
  Runners: method/run-emutos.sh (copied; only change: every *.LOG of hd/ is copied out),
  method/run-newtos.sh (copied; changes: KLINE env for a "#K de" layout line, list of logs).
  NewTOS keyboard layout: PROBE-NEWTOS-raspi4b(-repeat) and KEYS-* ran with "#K de" in NEWDESK.INF,
  PROBE-NEWTOS-raspi4b-us without. The EmuTOS ROM is etos512de, but its active layout on the oracle is

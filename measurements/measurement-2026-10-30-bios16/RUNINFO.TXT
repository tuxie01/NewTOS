  W01-W04  Super(0); LONG at 4*n := 0x00ABC000|4n; Setexc(n,-1) in super state; old value written
           back directly; Super(ssp); Setexc(n,-1). n = 0x02 ($008), 0x20, 0xFF ($3FC), 0x101 ($404)
  S01      $080 written in a Supexec callback, Setexc(0x20,-1) in user state, written back the same way
  E01      the same for etv_term ($408); written back before anything could end the program
  T01/T02  a child (the probe itself, "child") writes $080 in super state, checks Setexc(0x20,-1),
           Super(ssp), Pterm without putting it back; the parent asks Setexc(0x20,-1); T03 puts it back
  V01      swv_vec ($46E) against OSHEADER reseth (sysbase+4) and prt_vec ($50A, just_rts)

WHAT THE SNAPSHOTS SHOW
  All 10 snapshots: lost 0, interrupt transfer errors 0. The Unifying/Rii/Cherry receivers have 2 functions
  used (keyboard iface 0, mouse iface 1), recorded per interface. F3 confirmed on real hardware.
  Mouse report length per device (boot protocol):
    Unifying (MX Master, MX Ergo)  4 bytes, byte 3 = wheel; MX Ergo 31/3, Rii 53/30 listed non-zero wheel reports
    Rii X8                          4 bytes with wheel
    Cherry DW 9000                  3 bytes only (1023 of 1023 listed mouse reports) -- no wheel byte in boot
                                    protocol, yet the table says "Rad: ja"; open question to the tester
    Logitech B100 046d:c077 (cable) 3 bytes only, low speed; its report descriptor (46 bytes) declares
                                    X, Y, Wheel (Usage 0x38) as 3 x 8 bit -> the wheel exists only in report
                                    protocol. Cause of #8 = boot protocol, see TASK/USB03.md.
  Only the first 1024 reports of each recording are listed, so a zero wheel count in a listing (MX Master)
  does not mean the wheel was not sent.

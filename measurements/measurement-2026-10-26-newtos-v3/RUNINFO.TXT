MEASUREMENT ONLY. No product code changed, nothing committed, nothing flashed, no card.

WHAT / WHY
  User decision 2026-10-26: re-record all NewTOS dumps in v3 on the current commit
  (QEMU, post-ARCH03) as a new measurement run; diffs are findings for triage.
  tosdump/reference/NEWTOS-* are NOT touched; the new files live only here.

  IMPORTANT PARAMETER DIFFERENCE: all eight NEWTOS-* references were recorded on a REAL
  Raspberry Pi 4 (1920x1080, 256 colours; commit messages fd0277e3, 0c2005c3, 524f04e6,
  09617918, 6d55de4e, ba4e56c5, daec9223, 07ea3fd0). QEMU raspi4b reports 640x480
  (DEV_TAB 639,479). So every payload comparison against the old files includes the
  geometry change; "payload changed" below is therefore NOT a regression signal by itself.
  The case tables are the originals: every old NEWTOS-*.BIN validates against the current
  tosdump/cases table (CRC equal, tosdiff --validate "accepted"). Dumper source = HEAD 0bc2d4fb
  (build id 0bc2), format 3, pointer 8 bytes, least significant word first.

WHAT / WHY
  Bconmap returned its function number 0x2C for every argument (XBIOS-CHARDEV-005); the pinned
  EmuTOS has Bconmap on every machine, and a program that reads Bconmap(-2) without the 0x2C
  check read page 0 as a table. Implemented per the user decision: the table EmuTOS builds on
  a machine that is neither Falcon nor TT (references/emutos/bios/serport.c:962-966,972):
  Bconmap(-1) = 6, Bconmap(-2) = a BCONMAP {maptab, 1, 6} in the IOREC page (EL0 read-write,
  never executable), every device but 6 = 0, Bconmap(6) = 6 with the save step; MAPTAB[0]'s
  five function pointers point at never-executable call targets (a call is an instruction
  abort whose crash report names "Bconmap MAPTAB function (not callable)"), its Iorec slot is
  Iorec(0)'s record. Spec docs/api/xbios/2c-bconmap.md, layouts docs/api/structures/bconmap.md,
  COMPATIBILITY "Bconmap: one entry" and "MAPTAB function pointers".

DUMPER EXTENSION (docs/TOS-REFERENCE-DUMPER.md section 6 "Super and Supexec in a BIOS-area table", section 3 arg tokens)
 - A BIOS-area call table may issue trap 1 for function 0x20 (Super) only; all other GEMDOS is refused ("waits for DUMPGDOS").
 - Two argument kinds: f:<n> = the dumper's callback n (0..2, tosdump/core/runner_call.c; record token 0xB0FC0000+n),
   t:0 = the token the last Super(0L) returned (record token 0xB0F50000).
 - Guard: Supexec only with one f: argument; Super only l:1, or the bracket l:0 ... t:0 (no nesting, must close; an explicit
   stack address is refused).
 - Separate table tosdump/cases/super-r1.tsv (9 cases, CRC 3D9C560E, sha256 83a7bdbc...). bios-r1.tsv, its CRC and the
   record format are unchanged.

     boundary is unreachable from the backend (the box is cell.clamp_to inside the cell), so no pixel can change; the "box outside
     the cell" refusal test only uses boxes far outside. Suggest one boundary case (x1 - x == cell_w) in glyph_refuses_*.

     proportionally to the kernel image size (+4096 B -> byte +0x10, +8192 B -> +0x20, measured).

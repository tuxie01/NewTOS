   function. Code: newkeys = if r[2..8].contains(&0x01) { oldkeys } else { &r[2..8] }; state returned = modn + newkeys
   (so the kept set is stored back, modifier from the report); is_key(u) = u > 0x03 in both loops. Matches 1-3.
   hid.rs unchanged: PREV[func] per function; keyboard_report is called with a fixed 8-byte boot buffer (len is not
   used for keyboards, unchanged by the commit).
   Reports of the unit tests checked against the capture 05AC020C.TXT: seq 116/117/118 = `36 10` / `01 x6` / `36 0d`,

# source for both sides of tosdump/probes/run-ksprobe.sh:
#   NewTOS  the tools/inject-arm.py script, armed launch:KSPROBE: <hz_200 ticks after the
#           launch> <IKBD byte> (make = scancode, break = scancode | 0x80)
#   EmuTOS  the same bytes as Hatari --cmd-fifo "hatari-event keydown|keyup <scancode>",
#           the tick differences as wall-clock pauses (1 tick = 5 ms), the first byte
#           0.3 s after C:\KSPROBE.RDY appears

# far below the repeat delay; 40 ticks between sequences; 1000 ticks (5 s) before F,
# in which the probe sees 1 s without a change and calls Kbshift(0x80).
